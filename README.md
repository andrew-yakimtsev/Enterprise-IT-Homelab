# Enterprise IT Homelab

## Project Overview

This project documents my journey building and administering a simulated enterprise IT environment using VMware Workstation Pro, Windows Server 2025, and Windows 11.

The goal is to develop practical System Administrator and Infrastructure Engineering skills through hands-on experience with enterprise technologies.

## Project Objectives

- Deploy and manage Windows Server environments.
- Configure Active Directory Domain Services (AD DS).
- Implement DNS and DHCP services.
- Manage users, groups, and Organizational Units.
- Configure and troubleshoot Group Policy.
- Administer Windows client computers.
- Implement file sharing, NTFS permissions, and security policies.
- Develop PowerShell automation skills.
- Practice troubleshooting, monitoring, and infrastructure documentation.
